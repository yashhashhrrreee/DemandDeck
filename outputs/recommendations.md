# DemandDeck — Recommendations for Data Job Seekers
**Based on:** 785,741 job postings, Jan–Dec 2023  
**Salary caveat:** Salary figures drawn from 22,003-posting subset (2.8% of total) — treat as directional, not precise benchmarks.

---

## Recommendation 1: Lock in SQL and Python first — everything else is secondary

SQL appeared in 384,849 postings and Python in 380,909. Combined, they account for more than 1 in 5 skill mentions across all skill-listed postings. No other skill clears 150,000 postings. These two are not differentiators — they are the entry condition for the majority of data roles. Every hour spent on a third skill before these two are solid is a worse investment.

**Action:** If you're missing one or both, make them the only priority until you can pass a real coding screen. SQL first (broader role coverage), then Python. Don't split time.

---

## Recommendation 2: Match your skill stack to the specific role, not a generic "data skills" checklist

The three core roles have sharply different skill profiles:

- **Data Analyst**: SQL (47% of postings), Excel (34%), Python (29%), Tableau (24%), Power BI (20%). Visualization and spreadsheet tools matter here.
- **Data Scientist**: Python (66%), R (35%), SQL (46%). ML and statistics tools dominate. Excel barely registers.
- **Data Engineer**: SQL (61%), Python (58%), AWS (33%), Azure (33%), Spark (29%). Cloud and pipeline infra, not BI.

Learning Tableau for a Data Engineer role, or Spark for a Data Analyst role, is wasted preparation. Pick a target role first, then build for that profile — not for a hypothetical "well-rounded" data generalist.

**Action:** Look up 10 job postings for your target role and note which skills appear in at least 5 of them. Build to that list, not to a generic skills checklist.

---

## Recommendation 3: Add one high-signal technical skill to move up the salary distribution — but know what you're buying

In the salary subset, skills like Kafka, PyTorch, Scala, Spark, and Airflow all cluster around a $147,500 median — roughly $55,000 above Excel ($92,500) and $22,500 above the overall median ($125,000). The salary gap is real, but so is the skill-investment gap: these are engineering and ML tools that require time to learn properly.

The more actionable version of this insight: cloud platform skills (AWS, Azure, GCP) appear at high pay tiers AND high posting volumes. AWS is in 145,381 postings with a median near $135k. That's the highest-volume, high-signal skill that's also learnable without a software engineering background.

**Action:** If you're targeting a salary step-up and already have SQL + Python, add one cloud certification (AWS or Azure) as your next skill. It's the highest-volume skill in the high-salary cluster and has structured learning paths with measurable credentials.

---

## Recommendation 4: Remote roles are worth targeting but require deliberate strategy — don't treat them as the default

Only 8.8% of postings (69,552 of 785,741) are listed as remote, and the remote salary premium is real: $128,830 vs $115,000 on-site median (+12%, +$13,830). But the applicant pool for remote roles is geography-unrestricted, which means competition is higher than for on-site roles in the same location.

Senior Data Engineer has the highest remote rate at 14.7% — still under 15%. For entry-level roles (Data Analyst at 6.8%), remote postings are even scarcer.

**Action:** Apply to remote roles, but don't filter exclusively on remote — especially early-career. On-site roles at a company with strong data practice will build skills faster through in-person mentorship and are less contested. Revisit the remote filter once you have a senior title, where remote prevalence roughly doubles.
